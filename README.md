# shamsi_calendar

**Overview**
This module introduces full Hijri Shamsi Calendar support in Odoo 17, seamlessly integrating the Hijri Shamsi date system into various Odoo functionalities. It enhances Odoo's core features by providing localized date management across the following components:

Views: Form, List, Calendar, Chat, and Activities.
Date Conversions: Accurate conversion between Gregorian and Hijri Shamsi dates.
User Experience: Simplified workflows with Hijri Shamsi date integration.

**Features**
Full support for Hijri Shamsi Calendar.
Applies to Odoo 17 views, forms, lists, and calendars.
Works across chat systems, scheduled activities, and other Odoo features.
Accurate conversion between Gregorian and Hijri Shamsi dates.
